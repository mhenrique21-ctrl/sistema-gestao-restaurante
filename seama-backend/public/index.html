Usuários do sistema

Usuário nunca é excluído — o histórico de vendas e caixa precisa saber quem fez o quê. Desativar tira da tela de login e corta o acesso na hora.

Grupos de adicionais

Um grupo existe uma vez só e vale para todos os produtos marcados nele. Mudou o preço do queijo aqui, mudou em todos os produtos de uma vez. Preço zero aparece como "grátis" na venda.

Compras vindas do App Gestão

Quando você lança uma compra no Gestão para a SEAMA, os itens chegam aqui. O vínculo diz qual produto do cardápio cada item da nota alimenta, e quantas unidades saem de cada embalagem — 1 multipack de 6 vira 6 latas. Feito uma vez, as próximas compras entram sozinhas.

Cor da categoria selecionada

Marca qual categoria está aberta no menu lateral da venda. A prévia mostra como fica sobre o fundo escuro da barra — a porcentagem é o contraste medido: quanto maior, mais fácil de identificar de relance.

Tamanho das letras

Cada linha é uma camada do sistema — os textos que você lê no mesmo momento e da mesma distância. Ajustar uma não mexe nas outras. A mudança aparece na hora; só vale para todos os aparelhos depois de salvar.
